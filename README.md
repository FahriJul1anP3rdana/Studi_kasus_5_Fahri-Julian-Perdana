Pertama, ada fungsi pemesanan hotel yang bertugas menentukan harga harian berdasarkan jenis kamar, yaitu dua ratus ribu untuk kamar standard dan tiga ratus lima puluh ribu untuk kamar deluxe. Di dalam fungsi ini juga disiapkan tarif nol sebagai cadangan keamanan agar program tidak error jika ada data yang tidak sesuai. Setelah itu harga harian dikalikan dengan durasi menginap untuk menghasilkan total biaya.

Kedua, program menggunakan perulangan while true pada saat meminta input jenis kamar. Tujuannya supaya pengguna dipaksa memasukkan pilihan yang benar. Kalau input kosong atau salah ketik, program akan menampilkan peringatan dan meminta pengguna mengisi ulang sampai benar.

Ketiga, untuk input tanggal masuk dan tanggal keluar juga menggunakan perulangan while true terpisah. Langkah ini memastikan tanggal tidak boleh dibiarkan kosong, lalu teks yang diinput pengguna otomatis diubah menjadi angka integer agar bisa dihitung.

Keempat, program menghitung lama menginap dengan mengurangi tanggal keluar dan tanggal masuk. Hasil perhitungan tanggal serta jenis kamar yang sudah valid lalu dikirim ke fungsi pemesanan hotel untuk dihitung total biayanya.

Kelima, bagian akhir program akan mencetak seluruh ringkasan transaksi ke layar, mulai dari jenis kamar, tanggal masuk, tanggal keluar, total malam menginap, hingga total biaya yang harus dibayar.
