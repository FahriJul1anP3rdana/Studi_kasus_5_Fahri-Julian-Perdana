Pertama saya membuat fungsi pemesanan hotel yang bertujuan untuk menentukan jenis kamar beserta harganya

<img width="302" height="113" alt="Screenshot 2026-09-23 144236" src="https://github.com/user-attachments/assets/3931f4be-76d1-4401-b55d-a32948200b6e" />

Yang kedua saya membuat untuk user bisa input nama kamar yang ingin di pesan, dan saya memakai while true jika nanti user salah atau mengkosongkan input 

<img width="267" height="185" alt="Screenshot 2026-09-23 144242" src="https://github.com/user-attachments/assets/fed2370b-0d4a-4f1b-9bf8-9a70addbceed" />

Yang ketiga, saya membuat untuk input tanggal masuk dan tanggal keluar juga menggunakan perulangan while true terpisah. Langkah ini memastikan tanggal tidak boleh dibiarkan kosong, lalu teks yang diinput pengguna otomatis diubah menjadi angka integer agar bisa dihitung.

<img width="229" height="35" alt="Screenshot 2026-09-23 144248" src="https://github.com/user-attachments/assets/3e0515eb-ffd5-4d69-9b9c-f14814582e08" />

Yang keempat, saya juga membuat program menghitung lama menginap dengan mengurangi tanggal keluar dan tanggal masuk. Hasil perhitungan tanggal serta jenis kamar yang sudah valid lalu dikirim ke fungsi pemesanan hotel untuk dihitung total biayanya.

<img width="238" height="67" alt="Screenshot 2026-09-23 144254" src="https://github.com/user-attachments/assets/071d5ee7-b7d4-4780-a817-452d4310da11" />

Yang kelima, bagian akhir program akan mencetak seluruh ringkasan transaksi ke layar, mulai dari jenis kamar, tanggal masuk, tanggal keluar, total malam menginap, hingga total biaya yang harus dibayar.
